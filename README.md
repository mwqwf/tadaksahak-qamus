# قاموس تدكصهك

قاموس لسان الإدكصهك (Tadaksahak، رمزه dsq) بالحرف العربي المشكول.

- `index.html`: صفحة القاموس والمراجعة ولوحة الحروف الموسّعة، وفيها جدول التحويل الآلي من الإملاء اللاتيني اللساني إلى العربي.
- القاعدة: المصادر المنشورة تقترح الكلمة فقط؛ الشروح والأمثلة من عمل المراجعين الناطقين، ولا يُنسخ نصّ من أي مصدر.
- حالة المدخل: مرشّح ← مؤكَّد من مراجع ← مثبَت باتفاق مراجعَين.
